# 反诈第一课 · 伪装问卷互动 H5

> 🎮 **在线体验**:https://starryecho-t.github.io/anti-fraud-quiz/
>
> 创意致敬:抖音原创作者 @泪季雨 的「心理调查问卷」H5。
> 本项目仅借鉴其「伪装问卷 + 渐进式反转」的互动形式,内容为原创反诈教育改编。

## 玩法说明

表面是一份普通的《大学生活习惯小调查》,答题全程毫无异常……
直到最后反转:**你刚才亲手交出的每一条信息,正是真实骗局的第一步。**

流程:伪装问卷(11题,全程零穿插) → 信息反转 → 骗子工作手记(4篇连播) → 反诈结课报告 → 谢谢参与 → 红包"毕业小测"

## 运行

单文件、零依赖、无需服务器。直接双击 `index.html` 即可,手机/电脑均可。

## 部署到 GitHub Pages

本项目已部署:https://starryecho-t.github.io/anti-fraud-quiz/

如需重新部署到自己的账号:

1. 新建仓库(如 `anti-fraud-quiz`),上传 `index.html`
2. 仓库 Settings → Pages → Branch 选 `main` → Save
3. 访问 `https://你的用户名.github.io/anti-fraud-quiz/`

## 修改题目 / 笔记

打开 `index.html`,修改:

- `QS` 数组 —— 题目(含选项、警觉得分、泄露信息文案)
- `NOTES` 数组 —— 骗子笔记(第 3 篇会自动引用用户填写的姓名/生日)
- `TIMELINE` 数组 —— 题目与笔记的穿插顺序

全部数据驱动,改文案即可,无需懂逻辑。

## 技术栈

纯 HTML + CSS + 原生 JavaScript(含 WebAudio 心跳音效,可关闭),单文件,零依赖。
